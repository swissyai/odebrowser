# Changelog

## Unreleased

Ode's first release, derived from Crest 0.8.52.

- Product: named Ode, with its own bundle identifiers, icon, update feed and
  signing key; every visible string says Ode; the heraldic icons and the app
  icon choice are gone.
- Arc import: the archive, recent history (up to 5,000 entries per Space),
  saved passwords and sign-ins come across with each Space, its pinned tabs,
  favorites, Today tabs and folders.
- Spaces: edited as name, colour, and an SF Symbol or emoji.
- Tabs: pages of tabs not shown for a while sleep; content blocking is
  installed into every Space on first run.
- Agents: an Agents Space by default, a bounded page snapshot, an activity
  log, gates for new sites, sensitive fields and downloads, per-agent site
  grants, one-click setup for Claude Code, Codex and Pi, and setup lines for
  OpenClaw, Hermes and other MCP clients through `ode-browser`.
- Intelligence, off by default: tidy tab titles and Tidy Today with Apple's
  on-device model, a model on the same Mac, or the person's own ChatGPT plan.
- Built-in assistant search providers start disabled.
- Feedback, issue reports and update feeds go to odebrowser.com.
