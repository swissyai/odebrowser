# Security

Security fixes ship in the latest Ode release.

Report a vulnerability privately, in either of these ways:

- GitHub private vulnerability reporting: open the repository's Security tab
  and choose "Report a vulnerability".
- Email security@odebrowser.com.

Include the Ode version and platform, the boundary you could cross (for
example one Space reading another's data, a page reaching an agent tool, or a
password leaving the Keychain), and the steps to reproduce it. Do not post
vulnerabilities on the feedback page or in a public issue.
