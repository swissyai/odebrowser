# Install from the Chrome Web Store

Ode for Mac installs Chrome extensions from the Chrome Web Store. Extensions run on pages that open in Chromium. Pages that open in WebKit run no extensions.

## Install a Chrome extension {#install-extension}

1. Switch to the Space that should have the extension.
2. Open the extension's page in the Chrome Web Store and click its Add to Chrome button.
3. Check the review, then click Add Extension.

The other Spaces of its [Sub-Space](../spaces/sub-spaces.md) group share it.

Extensions run only on pages that open in Chromium.

## The review before installing

After you click the store's button, Ode downloads the extension and checks that it's the real one from the Chrome Web Store. Then it shows a review:

1. Check the extension's name and the Verified Chrome Web Store package label.
2. Open Review Access and Compatibility to read what it asks to do. Where the extension allows it, turn on Withhold website access until I grant it.
3. To add it to more Spaces now, click Install in other Spaces… and choose them.
4. Click Add Extension, then Done.

You can also open Site Controls on the extension's store page and click Install Extension….

## After installing

- Find the extension in Site Controls, and pin it if you use it often. See [Pin extensions and use popups](../pin-extensions-and-popups/).
- To turn it off, change its settings or remove it, choose Ode > Settings, click the Space, then click Extensions.
- Extensions update themselves, as they do in Chrome.

## When you can't install

- Private windows don't install extensions.
- A locked Space has to be unlocked first.
- Ode can't install Firefox add-ons or Safari extensions. Look for the extension's Chrome version.
