# Firefox add-ons

Ode does not install Firefox add-ons from **addons.mozilla.org**.

Extensions in Ode for Mac run on the Chromium engine, which runs Chrome extensions from the Chrome Web Store. It cannot load a Firefox `.xpi` package. WebKit pages run no extensions.

## Use Firefox add-ons or Safari extensions {#firefox-safari-extensions}

Ode can't install Firefox add-ons or Safari extensions. Most have a Chrome Web Store version. Install that instead.

Many Firefox add-ons also publish a Chrome version. Look for the same extension in the Chrome Web Store and install it from there. See [Install from the Chrome Web Store](./install-chrome-web-store.md).
