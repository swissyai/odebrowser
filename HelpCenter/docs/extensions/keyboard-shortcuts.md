# Set extension keyboard shortcuts

Extensions can declare keyboard commands, such as opening their popup. Chromium keeps these shortcuts for each Space's installation, so changing one in Work does not change it in Personal. The Spaces of a [Sub-Space](../spaces/sub-spaces.md) group share one installation and its shortcuts.

## Set a keyboard shortcut for an extension {#extension-shortcuts}

1. Choose Ode > Settings, click the Space, then click Extensions.
2. Click Shortcuts… and set the keys for the extension's commands.

Ode's own shortcuts win when both use the same keys.

The page that opens is Chromium's own list of extension shortcuts for that Space.

## When a shortcut does nothing

Ode's own shortcuts come first. An extension shortcut runs only when no Ode command uses the same keys. Check **Settings → Shortcuts** for a conflict, and pick different keys for one of them.

A shortcut that opens an extension's popup shows it beside the extension's pinned icon, or beside the control that opens the window's extension list when the extension is not pinned.
