# Pin extensions and use extension popups

Extension actions belong to the Space. Pin the ones you use often and leave occasional tools in Site Controls.

## Open an extension action

1. Select **Site Controls** beside the address field.
2. Find the extension's icon in the extension action area.
3. Select the icon to run its action or open its popup.

A popup opens below the icon you selected, attached to the Ode window. It closes when you click outside it, press Escape, move or resize the window, or switch to another app.

Open the icon's menu for more choices: **Extension Settings…**, **Pin to Toolbar**, **Disable Extension**, **Manage Extension…**, **View on Chrome Web Store** and **Remove Extension…**. In a private window the menu offers only the choices that don't change the Space's installation.

## Pin an extension so it's always in view {#pin-extension}

1. Click Site Controls at the right of the address. Extensions are listed there.
2. Right-click the extension and choose Pin to Toolbar. It shows under the address.

You can also click the pin button beside the extension in Site Controls. Pinned icons stay in the Space's strip on the Start Page too.

To remove an icon from the strip, choose **Unpin from Toolbar**. Unpinning does not disable or uninstall the extension.

## Open an extension's settings

If the extension has a settings page, choose **Extension Settings…** from its menu, or expand it on the Space's Extensions page in **Settings** and select **Extension Settings**. The page opens in the Space that owns the installation.

## Use side panels

Extensions with a Chrome side panel open it as a card beside the page. Choose **Open Side Panel** from the action's menu, select the icon if the extension opens its panel that way, or let the extension open it itself. The panel belongs to the page it opened beside. Ode does not keep side panels after you quit.

:::note Space-local placement
Pinning is independent per device, and per Space except within a [Sub-Space](../spaces/sub-spaces.md) group, whose Spaces share one strip. A Work strip can hold work tools while Personal or another Mac uses a different set.
:::
