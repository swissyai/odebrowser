# Developer tools

## Preview a site at phone or desktop size {#developer-toolbar}

1. Choose Develop > Show Developer Toolbar.
2. Open Viewport Preview and choose a phone or desktop size, or Custom.
3. Choose Normal — Preview Off to go back.

Shortcut: **Shift-Command-I**

The toolbar opens by itself on local pages such as localhost. Turn that off in Settings > General.

The toolbar also has Copy Link, the capture tools, Toggle Console, Toggle Network Panel, Inspect Element and Site Settings. When the window is narrow, they move into its ••• menu.

## Phone and desktop sizes

Viewport Preview offers Compact Phone (375 × 667), Phone (390 × 844), Large Phone (430 × 932), Desktop (1280 × 800), Wide Desktop (1920 × 1080) and Ultrawide (2560 × 1080). Custom takes any width and height from 1 to 8192 CSS pixels; click Apply Custom Viewport. The preview changes the page's layout size only. It doesn't pretend to be another device or engine.

## Local pages

The developer toolbar opens by itself on local pages: localhost, private network addresses, .local and .test addresses, and files. Turn this off with Developer toolbar on local pages in Settings > General.

## Captures

In the developer toolbar, Capture Window offers two choices: Capture in Portrait Mode saves a tall picture of the page as a PNG file, and Copy Full Page Capture copies the whole page. Capture lets you drag a rectangle to copy part of the page.

## Inspect a page's code {#web-inspector}

1. Choose Develop > Show Web Inspector.
2. It opens inside the window for the page you're on. Do the same to close it.

Shortcut: **Option-Command-I**

Chromium pages open Chromium DevTools. WebKit pages open Web Inspector.

Developer tools can show and change what a page holds. Use them on sites you trust.
