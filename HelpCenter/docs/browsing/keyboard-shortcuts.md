# Keyboard shortcuts

These are the shortcuts Ode starts with. Commands without a shortcut are still in the menus and the Command Bar.

## See all keyboard shortcuts {#keyboard-shortcuts-list}

1. Choose Ode > Settings, then click Shortcuts.
2. Search for a command to see its keys. Menu items show their keys too.

## Change a keyboard shortcut {#customize-shortcuts}

1. Choose Ode > Settings, then click Shortcuts.
2. Click a command's shortcut and press the new keys. Ode warns you if they're already in use.
3. Use Reset to Default for one, or Reset All… for every shortcut.

## No shortcut yet

Duplicate Tab, Save or Unsave Current Tab, Move Sidebar to the Left or Right, Split With Next Tab, Remove Tab From Split, Show Archive, Show or Hide Reader, Toggle Content Blocking, Boost This Site, Share Page, Export as PDF, Save Web Archive and Open File have no shortcut until you give them one.

## Switching Spaces

Control-1 to Control-9 switch Spaces, as in Arc. macOS uses Control-Left Arrow and Control-Right Arrow to move between desktops; they switch Spaces in Ode too once you turn off Move left a space and Move right a space in System Settings > Keyboard > Keyboard Shortcuts > Mission Control. See [Switch Spaces with the keyboard](../spaces-and-isolation/#switch-space-keys).

## In Peek and Quick Window

Escape or Command-W closes a Peek or Quick Window. Command-O keeps its page as a tab.

## Shortcuts that clash

Some websites use keys Ode also uses, such as Command-S in a chat app. In Settings > Shortcuts, each shortcut's … menu says who gets them while the page has focus:

- Prefer Ode: Ode runs the command and the website never sees the keys. Opening, closing and switching tabs and windows always work this way, and switching Spaces starts this way.
- Use Both: the website gets the first press. If it keeps the keys, the top of the window says to press them again, and a second press within about two seconds runs Ode's command. Toggle Sidebar, Open Location, Find in Page, Print, Copy Page Link and Capture Page start this way, among others.
- Prefer Website: the website keeps the keys, and Ode runs its command only when the website doesn't use them. Every other shortcut starts this way.

If you give a command a text editing shortcut, such as Command-Z for Reopen Closed Tab, a text field you're typing in keeps Undo, and the command runs when no field can use the keys.

A shortcut needs Command, Option, Control or Shift, except a function key such as F12, which works on its own. When an extension's shortcut uses the same keys as an Ode command, Ode's wins; change one of them.
