# Support

## Help and GitHub issues

- Start with the [help guides](HelpCenter/docs), including [installation and updates](HelpCenter/docs/getting-started/install-and-update-mac.md) and [moving from another browser](HelpCenter/docs/getting-started/move-to-ode.md).
- [Search existing GitHub issues](https://github.com/swissyai/odebrowser/issues), including closed issues, before opening a new one.
- Use the [bug report form](https://github.com/swissyai/odebrowser/issues/new?template=bug_report.yml) or [feature request form](https://github.com/swissyai/odebrowser/issues/new?template=feature_request.yml). GitHub issues are public.
- To investigate or help with a fix, [build from source](README.md#build-from-source) and read [Contributing](CONTRIBUTING.md).

Before asking for a feature, check
[Not planned](Documentation/NotPlanned.md), which lists requests Ode has
decided against, with the reasons and what to do instead.

## Private feedback

For questions, feedback, bug reports or requests to import from another browser
that you prefer to send privately, email
[feedback@odebrowser.com](mailto:feedback@odebrowser.com).

In Ode, open Settings > About, then Share Feedback or Report an Issue.
Open Email lets you review and send in your email app; Copy Report works
with webmail. Opening email is not a delivery confirmation. Your draft
stays in Ode until you quit.

## Privacy and security

Leave out passwords, account details, private addresses and browsing history.
Security problems go to the address in [SECURITY.md](SECURITY.md), not the
feedback inbox.
